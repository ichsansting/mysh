# Package management is scoped to CLI tools/binaries via mise, not full system packages

Full system packages (via apt/dnf/pacman/brew) install shared libraries and intermix with OS-level dependencies; there is no generically safe way to reverse "everything mysh added" for them, so Teardown could only ever be best-effort. We scoped "Package" to mean a CLI tool/binary installed into an isolated, mysh-owned prefix via `mise` (itself self-bootstrapped by the mysh binary on first use, and removable by Teardown same as anything else in the Application Log). Full system packages (libraries, GUI apps, compilers) are explicitly out of scope. Consequence: Teardown is fully clean and reversible for everything mysh manages, at the cost of not being able to manage anything that requires a system-level install.
